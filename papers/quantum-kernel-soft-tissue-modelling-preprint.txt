Quantum kernel scoring coupled to finite
hyperelastic soft-tissue modelling for vascular

A finite-mathematics framework joining an exactly emulated six-qubit angle-encoding kernel
to incompressible Neo-Hookean and Mooney-Rivlin inflation of arterial wall
Independent preprint  Version 1.2  22 November 2026 (adds Section 11 and Appendix D; Section 10 added in v1.1)
Synthetic data only  No patient data  Quantum kernel classically emulated  No quantum advantage claimed

   Abstract. Vascular planning needs two different kinds of finite descriptor: a similarity score that places a
   case relative to lower- and higher-risk archetypes, and a mechanical prediction of how a vessel wall inflates
   under pressure. This preprint formalises both, in closed form, and couples them only at the level of a shared
   case record. The similarity score is a six-qubit angle-encoding quantum kernel, k(x,x')=j=16cos2[(j-j')/2]
   with j=(/2)fj, evaluated exactly by classical emulation on six synthetic archetypes. The mechanical model
   is finite hyperelastic inflation at fixed axial stretch: incompressibility gives r=_-1, Mooney-Rivlin strain
   energy gives a closed-form hoop stress, and the thin-wall Laplace law gives pressure as P=(H/R) _-2_.
   For a healthy-carotid preset the Neo-Hookean limit reproduces the operating diameters used in the
   companion application, 6.47 mm at 80 mmHg and 6.79 mm at 120 mmHg from a 6.0 mm unloaded diameter.
   Across five tissue presets, systolic wall stress is highest for the AAA wall preset (260 kPa, driven by radius,
   not stiffness alone), while stiff/calcified and synthetic-graft presets show the smallest pulsatile strain (0.77%
   and 0.99%). The kernel separates the diffuse-severe archetype (krm high=0.973) from the low-burden
   archetype (krm low=0.995), but a classical RBF kernel makes the same calls on every archetype, so no
   quantum advantage is claimed. Version 1.1 adds a Thomas-solved finite element model of intraoperative
   expansion and a catheter design sweep (Section 10): balloon lumen 1.20 to 6.00 mm at 629 kPa peak stress;
   oversized stent 6.50 mm at 659 kPa. Version 1.2 adds a health-economics scenario model (Section 11) with a
   ridge / gradient-boosting cross-check: in the scale scenario, Year 3 revenue reaches USD 108.09M, above USD
   100M (conservative: USD 59.63M) - a scenario, not a forecast. All results are synthetic, experimental and not
   for clinical decisions.

1 Two finite descriptors, one case record
A vascular case is routinely summarised twice. Clinicians ask how similar it is to cases that did well or
badly, and engineers ask how its wall will deform when pressurised. Those questions are usually answered
by unrelated software. The companion vascular-surgery application that motivated this work places them
side by side: a quantum machine learning (QML) Lab that scores cases against risk prototypes, and a
Simulation tab that inflates a soft-tissue model and reports its characteristics. This preprint is the
mathematical record of those two modules.
The coupling proposed here is deliberately weak. The kernel consumes a normalised clinical feature vector
f[0,1]6; the tissue model consumes a geometry and a pair of material constants. They share an identifier
and a workflow state, not a fitted joint distribution, and no claim is made that either predicts the other.
Every number in the application can be regenerated from the equations below and the code in the
appendices, with no hidden training set and no patient data.
Section 2 derives the kernel, Section 3 the inflation law, and Section 4 the coupled descriptor. Sections 5-6
report the experiments; Sections 7-9 discuss limits and methods; Section 10 (Version 1.1) adds a finite
element model of intraoperative device expansion and derives catheter design implications from it.
Section 11 (Version 1.2) adds a health-economics model with a machine-learning cross-check over three
years.

  Scope statement. This independent, not-peer-reviewed preprint is not affiliated with any hospital, device company
  or quantum hardware provider. Every case, preset and number is synthetic or a labelled assumption. The kernel is
  emulated exactly on a classical computer; no quantum hardware was used and no quantum advantage is claimed.

2 The finite quantum kernel

2.1 Six features, six qubits
Each case is reduced to six normalised features, in a fixed order: stenosis fraction, normalised age,
normalised lesion length, diabetes (0 or 1), smoking (0 or 1) and a normalised comorbidity burden.
Normalisation is part of the model definition, not a preprocessing detail: stenosis is divided by 100%, age
by 100 years, and lesion length by 100 mm, each clipped to [0,1]. Write the result as f=(f1,...,f6)[0,1]6.

Angle encoding maps each feature to one qubit rotation. The scale /2, rather than , is essential: with a
full  scale, two cases differing in a single binary feature would be exactly orthogonal, and the kernel
would collapse to zero for almost every clinically distinct pair.


               j = (/2) fj, |(f) = j=16 RY(j) |0 = j=16 [ cos(j/2)|0 + sin(j/2)|1 ]
                                                                                                             (1)


2.2 Closed-form fidelity kernel
Because the encoding is a product state with no entangling gates, the fidelity kernel factorises exactly. No
approximation, sampling or shot noise enters the numbers reported here.


                 k(f, f) = |(f)|(f)|2 = j=16 cos2((j  j)/2) = j=16 cos2((fj  fj)/4)
                                                                                                             (2)


Each factor lies in [cos2(/4),1]=[0.5,1] for features in [0,1], so the kernel lies in [2-6,1] and never vanishes
on the feature cube. That floor is a direct consequence of the /2 encoding scale in equation (1), and it is
why the moderate archetype in Table 3 retains a readable similarity to both prototypes instead of
collapsing to numerical zero.

2.3 Prototypes, score and finite Gram matrix
Scoring is prototype-based, following the application. Two fixed archetypes anchor the scale: a lower-risk
prototype pL=(0.15,0.30,0.20,0,0,0.20) and a higher-risk prototype pH=(0.85,0.75,0.80,1,1,0.80). The signed
score and its label are


                  s(f) = k(f, pH)  k(f, pL), label(f) = higher if s(f) > 0, otherwise lower
                                                                                                             (3)


For any finite case set {f(1),...,f(n)} the Gram matrix Kab=k(f(a),f(b)) is positive semidefinite by construction,
because it is a Gram matrix of state vectors. For the six archetypes of Section 6 the computed eigenvalues
are 0.100, 0.275, 0.458, 0.765, 1.565 and 2.838, all strictly positive, which the code in Appendix A verifies
rather than assumes.

                         K  0, min(K) = 0.100 > 0 (n = 6 synthetic archetypes)
                                                                                                             (4)

2.4 Classical comparator
Every kernel result is reported beside a classical Gaussian (radial basis function, RBF) kernel on the same
normalised features, so that any apparent separation can be checked against a standard baseline.


                                   kRBF(f, f) = exp(  f  f2 ),  = 2
                                                                                                          (5)


The comparator matters more than the kernel. On the synthetic archetypes below, the two kernels agree on
the label of every case. That agreement is reported as a result, not hidden as an inconvenience: on six
product-encoded features there is no separation, classical or quantum, that the other does not also find.

2.5 What entanglement would - and would not - change
Adding entangling gates or a second encoding layer (data re-uploading) would break the factorisation in
equation (2) and require either hardware or statevector simulation. It would not, by itself, create a clinical
signal where the features carry none. The product encoding is therefore kept, precisely because its kernel
is exact, auditable and honest about its limits.

3 Finite hyperelastic soft-tissue model

3.1 Kinematics of inflation
The vessel is a circular cylinder inflated at fixed length. Let R and H be the unloaded inner radius and wall
thickness, r and h their pressurised values, and   =r/R=D/D0 the circumferential stretch, where D0 is
the unloaded diameter. Axial stretch is fixed and incompressibility closes the system.


                              z = 1, r  z = 1  r = 1, h = H/, r = R
                                                                                                            (6)



                              I1 = 2 + 1 + 2, I2 = 2 + 1 + 2 = I1 (z = 1)
                                                                                                            (7)


The equality I1=I2 is special to this kinematics and simplifies the Mooney-Rivlin stress below; it does not
hold for general biaxial loading, and the model must not be quoted as if it did.

3.2 Strain energy: Neo-Hookean and Mooney-Rivlin

                 WNH = (/2)(I1  3), WMR = C10(I1  3) + C01(I2  3),  = 2(C10 + C01)
                                                                                                            (8)


Write the Mooney-Rivlin ratio as =C01/(C10+C01)[0,1], so C10=(1-)/2 and C01=/2. The Neo-Hookean
law is the limit 0. A linear-elastic law, offered in the application for comparison, is the small-strain limit
of the same equations and is not used for any headline number here, because pulsatile strains reach 35%
in the softest preset considered in early tests - far outside its range.

3.3 Hoop stress and the Laplace inflation law
For an incompressible isotropic material the hoop-minus-radial Cauchy stress difference follows from W.
Setting the radial stress to zero in the thin-wall approximation gives the hoop stress, and Laplace's law
converts it to pressure.


                                      =  [ (1  ) + 2 ] ( 2  2 )
                                                                                                            (9)



                                P =  h/r = (H/R) 2 , T = P r,  = T/h
                                                                                                           (10)


In the Neo-Hookean limit equation (10) collapses to a one-line inflation curve, which is the model's basic
sanity check.


                              PNH =  (H/R) ( 1  4 ),  = ( 1  PR/(H) )1/4
                                                                                                           (11)


Check. For the healthy-carotid geometry (D0=6.0 mm, H=0.60 mm) with =204 kPa, equation (11) gives
=1.079 at 80 mmHg, hence D=6.47 mm, and =1.132 at 120 mmHg, hence D=6.79 mm. These are the
operating diameters the companion application reports, so the finite model and the application agree in
the limit where both can be checked by hand. The Mooney-Rivlin values in Table 2 differ slightly (6.49 mm
and 6.87 mm), as they should once =0.25 softens the large-stretch response.

3.4 Characteristics reported by the simulation
Let Dd and Ds be the diameters at diastolic pressure Pd=80 mmHg and systolic pressure Ps=120 mmHg,
with  P=Ps-Pd=40 mmHg and pulsatile strain =(Ds-Dd)/Dd. The application reports six characteristics, all
finite differences of the inflation curve - none requires a derivative that the discrete model does not
possess.

                            Compliance C = (Ds  Dd)/P, Distensibility = /P
                                                                                                           (12)



                          Peterson modulus Ep = P/, Stiffness  = ln(Ps/Pd)/
                                                                                                           (13)



                    Systolic wall stress s = Ps rs/hs, Tension Ts = Ps rs, Ws = W(s)
                                                                                                           (14)


Equations (12)-(14) explain the pattern in Table 2 before it is seen: Ep and  blow up as 0, so a stiff vessel
is identified by its moduli, whereas the AAA preset is identified by tension and stress, which scale with
radius through equation (10) even when its strain is unremarkable.

4 Coupled descriptor and finite workflow
The coupled record for one case is the finite tuple


                         D = ( s(f), k(f, pL), k(f, pH), d, s, , C, Ep, , s, Ts, Ws )
                                                                                                           (15)


It sits inside the application's finite eight-state surgical workflow - Referred, Imaging, Planning, Consent,
Scheduled, In OR, Recovery, Follow-up - in which a case occupies exactly one state at a time and the
descriptor D is recomputed, not carried, when features or tissue parameters change. No transition
probabilities are fitted in this preprint; the workflow is a bookkeeping device that guarantees each
descriptor belongs to a named case at a named stage, including the imaging (PACS) stage at which
diameter, stenosis and lesion length are measured.
That separation is the framework's main methodological point. Kernel inputs come from imaging and
history; tissue inputs come from geometry and assumed material constants. Keeping their provenance
separate in D prevents a common error in coupled models, in which a material assumption silently re-
enters as if it were a measured clinical feature.

7 Discussion
The framework's contribution is auditability. Equation (2) can be checked on a pocket calculator for a
single feature; equation (11) can be checked for a whole vessel. Between those two checks, every number
in the companion application - a kernel score in the QML Lab, a diameter in the Simulation tab, a
characteristic in its grid - traces to a stated equation, a stated preset and code that regenerates it. For
experimental surgical software, that traceability is worth more than a marginal gain in separation on
synthetic data.
The mechanical results argue for reporting stress and stiffness separately in any coupled record, as
equation (15) does. The AAA preset would be missed by a stiffness-only screen (its  is the lowest in Table
2) and the calcified preset would be missed by a stress-only screen (its stress is the lowest). Together, s, Ts,
Ep and  cover both failure intuitions: a wall that is loaded too heavily, and a wall that can no longer move.

The kernel results argue for equal restraint. Prototype scoring is transparent - Table 3 can be read as a
definition, not just a result - but transparency is not validity. No archetype carries an outcome, so
sensitivity, specificity and calibration are undefined here, and any future version that attaches the score to
real outcomes would need a governed dataset, a pre-registered analysis and clinical oversight that this
preprint does not have.

8 Limitations
  Synthetic only. Cases, archetypes and tissue presets are constructed examples. No patient data,
  measured tissue data or clinical outcomes were used.
  Classical emulation. The quantum kernel is evaluated exactly in classical arithmetic. No quantum
  hardware, sampling or noise model is involved, and no quantum advantage is claimed.
  Thin-wall, isotropic, static tissue model. Residual stress, anisotropy (for example a Holzapfel-Gasser-
  Ogden fibre model), viscoelasticity, axial prestretch, perivascular support and damage are omitted. The
  AAA geometry in particular is reduced to an equivalent cylinder, which captures the Laplace radius
  effect and nothing about local curvature or thrombus.
  Fixed operating pressures. Characteristics use 80 and 120 mmHg for every preset, for comparability.
  Patient-specific pressures would change every value in Table 2.
  Unweighted features. All six kernel features enter with equal weight through the product in equation
  (2). Clinical weighting is a judgement the framework deliberately does not encode.
  Not for clinical decisions. Nothing here is a device, a validated predictor or a recommendation about
  any patient or procedure.

9 Methods
Kernel evaluation. Angles were formed as j=(/2)fj and the kernel evaluated as the product in equation
(2) in double precision. Gram eigenvalues were obtained by symmetric eigendecomposition. The RBF
comparator used =2 on the same normalised features.
Inflation solve. For each preset and target pressure, stretch was found by 80 bisection iterations on
equation (10) over [1,3]. Pressures were converted at 1 mmHg = 0.133322 kPa. Characteristics were then
evaluated from equations (12)-(14) at the solved diastolic and systolic stretches.
Reproducibility. Appendix A is the generator for Tables 1-3 and Figures 1-2, in condensed form; Appendix
B gives the equivalent kernel in JavaScript, as used in the application. Running either reproduces the
kernel table exactly; running Appendix A reproduces the tissue table to the rounding shown.

10 Finite element simulation of minimally invasive intraoperative expansion
Added in Version 1.1. The soft-tissue model of Section 3 is a single-ring inflation law: it predicts how one
representative cross-section inflates, but it cannot express a focal lesion, a device of finite length, or a limit
on how far the wall may be pushed - the three features that define a minimally invasive intraoperative
expansion, in which a balloon catheter or stent is delivered through the stenotic segment and opened
inside it. This section discretises the same material law longitudinally, so those features become
representable, while keeping every constant from Sections 3 and 5: the healthy-carotid material (mu = 204
kPa, alpha = 0.25, H = 0.60 mm) is the wall, and plaque enters only as a stiffening factor and a yield
threshold, both stated below. Section 10.6 then reads the computed cases backwards, as design
implications for the devices themselves.

10.1 Mesh, lesion profile and governing system
The vessel segment is 60 mm long and is divided into N = 16 ring elements of length Le = 3.75 mm, giving
17 nodes and, with the two end nodes fixed, 15 free radial degrees of freedom. The unknown is the nodal
radial displacement vector u. The reference (diseased, unloaded) lumen carries a focal Gaussian lesion
centred at zc = 30 mm,


   Dref(z) = Dnom - (Dnom - Dmin) exp( -(z - zc)2 / (2 sigmag2) ), Dnom = 6.0 mm, Dmin = 1.20 mm,
                                              sigmag = 1.55 mm
                                                                                                            (16a)


so the minimum reference lumen is 1.20 mm at the lesion centre and the profile has returned to within 0.3
mm of nominal one element either side of the centre node - a focal lesion, not a diffuse narrowing. Each
element e takes the mean of its two nodal reference diameters, Deref, and its own material constants.
Equilibrium of the discretised segment is the linear system

            K u = F, K tridiagonal, u = nodal radial displacements, F = device load vector
                                                                                                             (16)


which is solved exactly, in the finite sense used throughout this preprint, by the Thomas algorithm for
tridiagonal systems [9,10]: one forward elimination sweep and one back-substitution, with no iteration
error beyond floating-point rounding.

10.2 Element tangent stiffness
Element stretch is measured from the element-mean displacement, lambdae = (Deref + ui + ui+1) / Deref,
where i and i+1 are the element's nodes. The element tangent stiffness is the derivative of the Mooney-
Rivlin hoop stress of equation (9), converted from a stretch tangent to a displacement tangent by the
element radius, since the hoop resultant sigmatheta h Le changes with displacement through d lambda =
du / r:


    ke = (d sigmatheta / d lambda)e  (he / re)  Le, d sigmatheta/d lambda = mue [ -2 alpha lambda-
            3(lambda2 - lambda-2) + ((1 - alpha) + alpha lambda-2)(2 lambda + 2 lambda-3) ]
                                                                                                             (17)


Assembling the element stiffnesses into the two nodes each element touches produces the tridiagonal K of
equation (16): each free diagonal entry collects the two adjacent elements, and each off-diagonal entry is
the shared element's stiffness. No other coupling is present - there is no bending stiffness and no axial
stress resultant, a limitation Section 10.7 states plainly.

10.3 Device load and contact cap
A device of nominal diameter Ddev and length Ldev, centred on the lesion, loads every node inside its
footprint with the pressure resultant on that node's tributary area. The device may not push any node past
its nominal diameter, which enters as a displacement cap applied by an active-set pass: nodes whose
unconstrained displacement exceeds the cap are held at the cap, the remaining system is re-solved, and
held nodes are counted as contact nodes.


                   Fi = Pdev Le Ddev (loaded nodes), ui  (Ddev - Diref) / 2 (contact cap)
                                                                                                                    (18)


The total device force reported in Tables 4 and 5 is the pressure resultant over the reference inner surface
of the elements the device spans, Ftot = sume Pdev pi Deref Le. A balloon and a stent differ in this model
only through (Pdev, Ddev, Ldev): the balloon case uses a higher pressure at the nominal vessel diameter
over a short footprint; the stent case uses a lower deployment pressure, a longer footprint, and a nominal
diameter oversized by 0.5 mm relative to the vessel, as is standard sizing practice. No stent strut geometry
is represented.

10.4 Plaque stiffening and yield softening
Plaque is represented in two places. First, each element's shear modulus is stiffened in proportion to its
local stenosis fraction se = 1 - Deref/Dnom, with stiffening factor phi = 2.5 at full stenosis. Second, when an
element's elastic hoop stress exceeds the yield stress sigmay = 600 kPa, the element is treated as yielded: its
stress follows the softened line below and its tangent modulus is reduced to a fraction 0.216 of its tangent
at yield for the next solver pass.

  mue = mu [ 1 + (phi - 1) se ], sigmae = sigmay + 0.216  sigma'(lambday) (lambdae - lambday) for
                                            yielded elements
                                                                                                                    (19)


The solve therefore takes two passes in both cases of Table 4: a first, elastic pass that identifies the yielded
set, and a second pass with the yielded tangents softened. Yielding is a modelling device for plaque
fracture and stress relief, not a measured plaque property.

10.5 What the comparison shows
Three features of Table 4 are structural, not parametric accidents. First, the maximum stress sits at the
lesion centre in both cases even though the load is uniform over the footprint, because the centre elements
combine the largest stretch with the largest plaque stiffening - the longitudinal analogue of the radius
effect in Section 6.1. Second, the yielded set is the same two elements (a 7.5 mm zone) for both devices: at
these diameters the centre elements pass the 600 kPa yield stress under either device, while their
neighbours, one element away, peak at 82 kPa (stent) and 18 kPa (balloon). Yielding here is a property of
the lesion geometry, not of the device choice. Third, the stent's total device force is higher (293 N against
223 N) despite its lower pressure, because the force resultant scales with the reference surface the device
spans, and the stent spans six elements against the balloon's four; pressure alone is therefore as
incomplete a device descriptor as stiffness alone was a tissue descriptor in Section 6.
The stent's larger lumen gain (5.30 mm against 4.80 mm) is bought with a higher peak stress (659 kPa
against 629 kPa), because the oversized cap drives the centre elements further along the softened post-
yield line of equation (19). Both residual stenoses are reported at pressure, with the device in place;
neither number is a post-procedure outcome, and the balloon figure in particular would fall once deflation
recoil - which this static model does not contain - is accounted for.

10.6 Design implications for balloon catheters and stents
Reading Table 4 as a designer rather than an analyst - what should be chosen, and what does each choice
cost? - is a small step, because the model's three device parameters map one-to-one onto the three
quantities a catheter designer actually specifies: nominal diameter, length and rated pressure. Table 5
varies each in turn around the Table 4 cases, holding the lesion, wall and mesh fixed. Four rules emerge,
each traceable to one equation.
Nominal diameter is the lumen (equation 18). In every variant whose load reaches the cap, the treated
lumen equals Ddev exactly, so diameter selection is lumen selection. Undersizing the balloon to 5.5 mm
(B3) caps the gain at 4.30 mm and leaves 8.3% residual stenosis; oversizing the stent by 0.5 mm (S1 against
S3) adds the full 0.50 mm of gain. The cost of oversizing is set by the post-yield slope of equation (19), 0.216
 sigma'(lambday) = 206 kPa per unit stretch, or about 59 kPa per additional millimetre of diameter at this
lesion: the 0.5 mm oversize costs exactly the observed 30 kPa (629 to 659 kPa). Diameter is therefore the
one parameter that trades lumen against wall stress, and the trade is priced by the yield line, not by the
elastic law.
Pressure only has to reach the cap (equations 16 and 18). Dropping the balloon from 10 atm to 8 atm
(B2 against B1) changes nothing about the result - same lumen, same peak stress, same yielded set, same
contact nodes - except total force, which falls from 223 N to 178 N in proportion to pressure. Once every
footprint node is capped, additional pressure buys no lumen; it only raises the force the wall and the
catheter shaft must carry. In this model a rated pressure is therefore correctly sized to the minimum that
caps the stiffest element, not maximised.
Length buys coverage and force, not stress relief (equation 16). Shortening the stent from 24 mm to 15
mm (S2 against S1) leaves peak stress and lumen gain unchanged, while contact nodes fall from 7 to 5 and
total force from 293 N to 178 N. Length should be chosen to cover the lesion with margin - the yielded zone
is 7.5 mm, and both footprints cover it - because length beyond the lesion loads healthy wall at the cap
without reducing lesion stress.
Yielding is lesion-set, so stiffness is a lesion property before it is a device property (equation 19). The
same two elements yield in all six variants of Table 5, across both device types and every parameter
change. What the device parameters move is the stress level on the post-yield line (607-659 kPa) and the
force, never the yielded set; and the stress concentration itself is created by the plaque stiffening of
equation (19), with neighbour elements peaking at or below 82 kPa. A design response to peak stress in this
model is therefore a diameter response, or a lesion-preparation response that changes the stiffening itself -
not a pressure or length response.

10.7 Limits of the finite element and design analysis
   One-dimensional ring elements. No bending, no axial stress resultant, no balloon folding, dog-boning
   or stent strut geometry; longitudinal coupling is the tridiagonal system of equation (16) and nothing
   more, so the design rules of Section 10.6 are rules inside this discretisation, not bench or clinical
   findings.
   Contact cap is a constraint, not a contact solve. Capped nodes are held at the nominal device
   diameter by an active-set pass; friction, slip, compliance of a real balloon (which grows with pressure)
   and partial contact are not modelled - a real balloon's diameter is not the hard cap equation (18)
   assumes.
   Plaque is a factor and a threshold. The stiffening factor phi and yield stress sigmay are modelling
   assumptions; no plaque composition was measured, and the lesion profile of equation (16a) is the
   synthetic default, stated in full so it can be replaced.
   Static loading. No pulsatile pressure, viscoelasticity or recoil after deflation, so residual stenosis is an
   at-pressure result and the design trade-offs omit recoil, fatigue and deliverability entirely.
   Not device guidance. Nothing in Sections 10.6-10.7 is a sizing recommendation for any real catheter,
   stent, lesion or patient. Independent, not peer-reviewed, synthetic-only, no patient data, experimental
   and not for clinical decisions.

11 Health economics: costs, revenue and a three-year trajectory
Sections 2-10 price nothing. This section (Version 1.2) adds the missing economic layer: a bottom-up cost
and revenue model for a hypothetical commercial deployment of the kernel-plus-simulation platform,
projected over three years, with a statistical machine-learning model fitted as an independent arithmetic
cross-check. The framing discipline of the earlier sections applies unchanged: every price, adoption count
and effect size below is a labelled synthetic assumption, the trajectory is a scenario, not a forecast, and no
revenue figure here is a claim about any real company, hospital or product.

11.1 Revenue identity and cost components
Revenue has three components, matching the three things the platform does. Each treated case pays a per-
case software fee for kernel scoring and simulation; each active site pays an annual licence; and each case
treated with a catheter or stent whose design used the Section 10 finite element sweep pays a per-case
design royalty. With St active sites, Nt cases, per-case fee pt, licence L, FE-designed share qt and royalty r,

                                         Rt = Nt pt + St L + Nt qt r, Nt = 12 St ct
                                                                                                                     (20)


where ct is cases per site per month. Costs are a variable cost per case (compute, support, quality and
regulatory overhead allocated per case) plus fixed operating cost (engineering, clinical-affairs and sales
teams), both in Table 6 for the central ("scale") scenario.

11.2 Payer perspective: what a case must save
Provider revenue is a payer cost, so a health-economics section must state the other side of the ledger. In
Year 3 the platform charges, per case, the fee plus the licence and royalty amortised over volume: 800 +
13.60M/97,920 + 16.16M/97,920 = USD 1,104 per case. If the platform's only monetised benefit were avoided
reinterventions at an assumed USD 18,500 per reintervention, the absolute reduction in reintervention
probability needed to break even is

 p* = (platform price per case) / (cost per reintervention) = 1,104 / 18,500 = 5.97 percentage points
                                                                                                          (21)


At a purely hypothetical 2.1-percentage-point reduction, the expected avoided cost is USD 389 per case -
well short of the price. The scenario therefore does not claim cost savings for payers: at the stated prices it
is a net cost to the health system unless outcome effects near 6 percentage points, or other benefits (shorter
procedures, fewer complications, capacity release), are demonstrated. None is demonstrated here;
equation (21) simply marks where the burden of proof lies.

11.3 Statistical machine learning: a fitted cross-check
The accounting identity (20) is exact but unfitted - it assumes its conclusion. To test whether a statistical
learner, shown only noisy site-level data, recovers the same economics, a synthetic panel of 160 sites x 24
months (3,840 site-months) was generated from equation (20) at site-month level, with Poisson case counts,
three price/licence tiers, a ramping FE-designed share, site effects and Gaussian noise (sigma = USD 250). A
ridge regression on engineered features x = (cases, fee, share, cases x fee, cases x share, licence) was fitted
on months 1-18 and tested on months 19-24,


              w = argminw || y - Xw ||2 +  ||w||2,  = 0.01 by 5-fold cross-validation
                                                                                                          (22)


with a gradient-boosted ensemble of depth-2 regression trees (200 rounds, learning rate 0.1, implemented
directly in NumPy) on the raw features as a non-linear comparator. On the held-out months the ridge
model reaches R2 = 0.997 (RMSE USD 408 per site-month) and the boosted trees R2 = 0.989 (RMSE USD 813).
More informative than either score, the back-transformed ridge coefficients recover the data-generating
prices: 0.97 on cases x fee (true value 1, the fee itself) and USD 301 on cases x share (true royalty USD 300).
The licence coefficient is attenuated to 0.53 because licence tier and fee tier are collinear in the panel -
reported here rather than tuned away, as a reminder that even a near-perfect R2 does not identify every
price separately.

 # --- gradient boosting, depth-2 trees, implemented directly ---
 def best_split(Xs, rs, min_leaf=60):
     b = (np.inf, None, None)
     for j in range(Xs.shape[1]):
         for q in np.quantile(Xs[:, j], np.linspace(.1, .9, 9)):
              L = Xs[:, j] <= q
              if L.sum() < min_leaf or (~L).sum() < min_leaf: continue
              sse = ((rs[L]-rs[L].mean())**2).sum() \
                  + ((rs[~L]-rs[~L].mean())**2).sum()
              if sse < b[0]: b = (sse, j, q)
     return b

 def build(Xs, rs, d):
     node = {"val": rs.mean()}
     if d == 0 or len(rs) < 120: return node
     sse, j, q = best_split(Xs, rs)
     if j is None: return node
     L = Xs[:, j] <= q
     node.update(j=j, q=q, left=build(Xs[L], rs[L], d-1),
                 right=build(Xs[~L], rs[~L], d-1))
     return node

 def tpred(node, X):
     if "j" not in node: return np.full(len(X), node["val"])
     L = X[:, node["j"]] <= node["q"]
     out = np.empty(len(X))
     out[L] = tpred(node["left"], X[L])
     out[~L] = tpred(node["right"], X[~L])
     return out

import math
MMHG = 0.133322   # kPa per mmHg

def hoop_stress(lam, mu, alpha):
    return mu * ((1 - alpha) + alpha * lam**-2) * (lam**2 - lam**-2)

def pressure_kpa(lam, mu, alpha, H_R):
    return H_R * lam**-2 * hoop_stress(lam, mu, alpha)

def lam_at(P_mmHg, mu, alpha, H_R):
    target, lo, hi = P_mmHg * MMHG, 1.0, 3.0
    for _ in range(80):
        mid = (lo + hi) / 2
        if pressure_kpa(mid, mu, alpha, H_R) < target: lo = mid
        else: hi = mid
    return (lo + hi) / 2

    for a, b in zip(f, g):

    return k

 // Quantum kernel - exact classical emulation, 6 qubits, angle encoding
 function quantumKernel(f, g) {
   let k = 1;
   for (let j = 0; j < 6; j++) {
     const dTheta = (Math.PI / 2) * (f[j] - g[j]);
     k *= Math.cos(dTheta / 2) ** 2;   // per-qubit fidelity factor
   }
   return k;
 }
 const P_LOW = [0.15, 0.30, 0.20, 0, 0, 0.20];
 const P_HIGH = [0.85, 0.75, 0.80, 1, 1, 0.80];
 function kernelScore(f) {
   const kLow = quantumKernel(f, P_LOW);
   const kHigh = quantumKernel(f, P_HIGH);
   return { kLow, kHigh, score: kHigh - kLow,
            label: kHigh > kLow ? "higher" : "lower" };
 }

 // Soft tissue - Mooney-Rivlin hoop stress and Laplace pressure (kPa)
 function hoopStress(lam, mu, alpha) {
   return mu * ((1 - alpha) + alpha / lam**2) * (lam**2 - 1 / lam**2);
 }
 function pressureKPa(lam, mu, alpha, H_R) {
   return H_R * hoopStress(lam, mu, alpha) / lam**2;
 }
 function diameterAt(PmmHg, preset) {
   const H_R = preset.H / (preset.D0 / 2), target = PmmHg * 0.133322;
   let lo = 1, hi = 3;
   for (let i = 0; i < 80; i++) {
     const mid = (lo + hi) / 2;
     if (pressureKPa(mid, preset.mu, preset.alpha, H_R) < target) lo = mid;
     else hi = mid;
   }
   return preset.D0 * (lo + hi) / 2;
 }

 LE = L_SEG / N                      # 3.75 mm
 ZC, D_NOM, D_MIN, SIG_G = 30.0, 6.0, 1.20, 1.55
 H, MU, ALPHA, PHI = 0.60, 204.0, 0.25, 2.5
 SIGMA_Y, SOFT = 600.0, 0.216        # kPa; post-yield tangent fraction
 Z = [i * LE for i in range(N + 1)]
 DREF = [D_NOM - (D_NOM - D_MIN) * math.exp(-((z - ZC) ** 2) / (2 * SIG_G ** 2)) for z in Z]
 DE = [(DREF[e] + DREF[e + 1]) / 2 for e in range(N)]
 MUE = [MU * (1 + (PHI - 1) * (1 - DE[e] / D_NOM)) for e in range(N)]

 def stress(lam, mu):
     return mu * ((1 - ALPHA) + ALPHA * lam ** -2) * (lam ** 2 - lam ** -2)

 def tangent(lam, mu):
     A = (1 - ALPHA) + ALPHA * lam ** -2
     return mu * (-2 * ALPHA * lam ** -3 * (lam ** 2 - lam ** -2)
                  + A * (2 * lam + 2 * lam ** -3))

 def lam_yield(mu):
     lo, hi = 1.0, 4.0
     for _ in range(80):
         mid = (lo + hi) / 2
         if stress(mid, mu) < SIGMA_Y: lo = mid
         else: hi = mid
     return (lo + hi) / 2

 def thomas(a, b, c, d):
     n = len(d); cp = [0.0] * n; dp = [0.0] * n
     cp[0] = c[0] / b[0]; dp[0] = d[0] / b[0]
     for i in range(1, n):
         m = b[i] - a[i] * cp[i - 1]
         cp[i] = c[i] / m if i < n - 1 else 0.0
         dp[i] = (d[i] - a[i] * dp[i - 1]) / m
     x = [0.0] * n; x[-1] = dp[-1]
     for i in range(n - 2, -1, -1):
         x[i] = dp[i] - cp[i] * x[i + 1]
     return x
