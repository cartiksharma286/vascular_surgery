   Abstract

   Pharmacogenomic states - reproducible patterns of germline variants, somatic alterations and gene
   expression that predict drug response - are now defined at population scale by classical genomics.
   Whether quantum machine learning (QML) adds anything beyond a classical classifier for such states
   remains unproven. This preprint makes the question finite and therefore testable. We formalise a
   pharmacogenomic signature as a function on a finite genotype alphabet, embed it in a finite-
                                     n
   dimensional Hilbert space C2 via angle encoding, and derive finite-sample generalisation bounds that
   do not rely on asymptotic quantum advantage. We then embed the signature in a complete clinical
   trial management protocol: pre-registered eligibility, signature-stratified randomisation, a finite-state
   Markov model of trial states, Bayesian interim monitoring with explicit stopping boundaries, and
   multiplicity control across a finite family of hypotheses. A fully reproducible synthetic-data
   experiment, with complete Python source code in the Appendix, shows a quantum-kernel classifier
   performing comparably to - not better than - a classical radial-basis-function support vector machine.
   The contribution is the auditable framework and management protocol, not a claim of quantum
   advantage, clinical efficacy, or an AstraZeneca product. Part II (Sections 8-10) adds a finite, discounted
   10-year health-economics and trajectory model for Sunnybrook's Odette Cancer Centre, 2027-2036,
   built on published scale figures only, with all treatment effects as hypothetical assumptions.

   Keywords: quantum machine learning; pharmacogenomics; quantum kernel; finite-sample bounds;
   adaptive trial; health economics; Sunnybrook; Odette Cancer Centre; AstraZeneca (context only)

1 Introduction: genomics defines the problem, QML is only a candidate solver
Modern pharmacogenomics begins classically. Large sequencing programmes - AstraZeneca's Centre
for Genomics Research, built around up to two million genome sequences including more than 500,000
from its own clinical trials, is a prominent industry example - link variants and expression to disease
biology and drug response. A signature learned from such data can select patients for a trial, stratify
randomisation, or define a companion diagnostic hypothesis. None of that requires a quantum
computer.

Quantum computing enters AstraZeneca's public record elsewhere: hybrid quantum-classical
chemistry workflows, quantum-inspired drug-discovery partnerships, and exploratory work with IBM
Quantum on clinical-data imputation and lead-compound selection. Conflating the two programmes
would be an error. The correct scientific question is narrower: given a classically defined, finite
pharmacogenomic feature set, does a quantum feature map classify response states better, on finite
samples, than the best classical kernel - and can that comparison be run inside a properly managed
trial?


2 Finite mathematics framework

2.1 Finite genotype and expression alphabet
Let each patient be described by d features. After pre-registered discretisation, feature j takes values in
a finite alphabet Aj with |Aj| = mj (for example, genotype in {0,1,2} copies of a minor allele, so mj = 3).
The patient space is therefore finite:

                                 X = A1 x ... x Ad,    |X| = prodj=1..d mj < infinity.

A pharmacogenomic state is a label y in Y = {0,1} (non-responder, responder) or a finite set of subtypes
Y = {1,...,K}. A signature is a function s: X -> Y. Because X and Y are finite, the total number of possible
signatures is |Y||X| - astronomically large but finite, which is exactly what makes counting-based
bounds possible.

2.2 Finite-dimensional quantum embedding
Encode a scaled feature vector x in [0, pi]d on n qubits (n >= d, one feature per qubit in the simplest
scheme) by angle encoding:

                                                                                           n
                      |phi(x)> = tensorj=1..n [ cos(xj/2)|0> + sin(xj/2)|1> ] in H = C2 .

H is finite-dimensional: dim H = 2n. The quantum kernel is the squared overlap, computable on
hardware by an inversion test and exactly in simulation:

                             kQ(x, x') = |<phi(x)|phi(x')>|2 = prodj cos2((xj - x'j)/2).

Entangling layers replace this product form with a general unitary U(x) and kQ(x,x') = |
<0|Udagger(x)U(x')|0>|2, still a finite matrix computation in dimension 2n.

2.3 Finite-sample generalisation bound

Let H be a finite hypothesis class of signatures, |H| finite, and let err(h) be true error and err-hat(h)
empirical error on N independent patients. Hoeffding's inequality plus a union bound over the finite
class gives, for any epsilon > 0:

                P( exists h in H : |err(h) - err-hat(h)| > epsilon ) <= 2|H| exp(-2 N epsilon2).

Setting the right-hand side to delta and solving for N gives the finite sample complexity used for trial
sizing in Section 4:


   Proposition 1 (finite signature sample size). To guarantee, with probability at least 1 - delta, that
   every candidate signature's empirical error is within epsilon of its true error, it suffices that


   N >= (1 / 2 epsilon2) . [ ln|H| + ln(2/delta) ].


   Example: |H| = 1,000 candidate signatures, epsilon = 0.05, delta = 0.05 gives N >= 200 x (6.91 + 3.69) =
   2,120 patients. The bound is conservative - deliberately so for a pre-registered trial.


For kernel classifiers the same finiteness appears through the Gram matrix: on N patients, K is an N x N
positive semidefinite matrix, the dual problem has at most N variables, and the representer theorem
confines the solution to span{k(., xi)}. Nothing infinite enters the computation.


2.4 Finite trial states as a Markov chain
Trial management is modelled on a finite state set S = {Screening, Eligible, Randomised, On-treatment,
Follow-up, Completed, Withdrawn, Safety-hold}. Transitions form a row-stochastic matrix P in R8x8, Pab
>= 0, sumb Pab = 1. After t steps the occupancy distribution is vt = v0 Pt, a finite vector computation.
Expected time to absorption (Completion or Withdrawal) follows from the fundamental matrix of the
absorbing chain:

                               M = (I - Q)-1,   expected steps to absorption = M . 1,

where Q is the transient-to-transient submatrix. This gives a closed-form forecast of screening load and
completion times from observed transition counts.


3 Methods: signature learning

Features (pre-registered). Germline pharmacogene variants (for example CYP2D6, CYP2C19, DPYD,
UGT1A1 activity scores), somatic alterations where relevant, and binned expression of a fixed gene
panel. Feature list, bins and scaling to [0, pi] are frozen before unblinding.

Classifiers compared. (i) Quantum-kernel SVM using kQ above (exact simulation; hardware execution
is a drop-in replacement for the kernel matrix). (ii) Classical RBF-kernel SVM, tuned by nested cross-
validation. (iii) Logistic regression as a transparent baseline. Primary metric: area under the receiver
operating characteristic curve (AUC) on a held-out test set, with balanced accuracy and calibration
reported secondarily.

Leakage control. Preprocessing is fit on training folds only; the test set is touched once; kernel, grid
and threshold are named in the analysis plan before test evaluation.

4 Clinical trial management protocol

4.1 Design
A two-stage, signature-stratified, double-blind randomised design. Stage 1 (learning, N1 patients)
estimates the signature under Proposition 1 sizing. The signature is then locked. Stage 2 (confirmatory,
N2 patients) randomises within signature-positive and signature-negative strata, so the treatment-by-
signature interaction - the actual pharmacogenomic claim - is estimated without re-using learning data.

4.2 Finite sizing for the confirmatory stage
For a responder-rate difference p1 - p0 = D in a stratum, the usual normal-approximation size per arm,
kept finite and explicit, is:

                             narm = (z1-alpha/2 + z1-beta)2 [p1(1-p1) + p0(1-p0)] / D2.

Worked example: p0 = 0.30, p1 = 0.50, D = 0.20, alpha = 0.05, power 0.90 gives narm = (1.96 + 1.28)2 x (0.21
+ 0.25) / 0.04 = 10.50 x 0.46 / 0.04, approximately 121 per arm. Inflating by 10% for withdrawal gives 135
per arm, 270 per stratum. These are planning numbers, not results.

4.3 Bayesian interim monitoring
Within each stratum, responder counts follow a binomial likelihood with a Beta(1,1) prior, so the
posterior is Beta(1 + r, 1 + n - r) in closed form. Stop for efficacy if P(ptreat > pcontrol | data) > 0.99; stop
for futility if predictive success probability falls below 0.10. Thresholds are calibrated by simulation
(Appendix A) to keep type I error at or below 0.05.

4.4 Operations and data management
    Systems: electronic data capture with the Markov state of Section 2.4 as the patient-status field;
    every transition is timestamped and audit-trailed.
    Signature lock: the locked kernel matrix definition, code hash and feature bins are filed with the
    trial master file before Stage 2 opens.
    Deviations and reporting: any post-lock change is a protocol amendment; CONSORT flow uses the
    same finite states so counts reconcile exactly.

0.90 under the planning alternative. A protocol should not proceed if its simulation fails either check.


6 Discussion

What this framework buys. Finiteness is a discipline: a finite alphabet forces explicit discretisation, a
finite hypothesis family forces an honest sample size (Proposition 1), a finite state model forces
operations to reconcile, and closed-form Beta posteriors give monitoring rules that can be checked by
hand.

Limitations. First, current quantum hardware is noisy and small (the NISQ regime), and loading
classical genomic data into quantum states can erase any theoretical speedup. Second, the product
angle-encoding kernel used here is classically simulable by construction - it is a fairness baseline, not a
candidate for advantage; entangling kernels need hardware validation and noise analysis. Third,
synthetic data cannot capture linkage disequilibrium, stratification, batch effects or missingness.
Fourth, a signature may not transport across ancestries or care settings; external prospective validation
is mandatory. Fifth, no quantum advantage is shown here or in the published QML-for-genomics
literature to date.

Relation to industry programmes. Nothing here reports or implies access to AstraZeneca data,
compounds or trials. AstraZeneca is public context only: large-scale classical genomics plus separate
quantum pilots - a natural example for asking rigorously whether the two should meet in a trial.


7 Conclusion

A pharmacogenomic QML signature can be stated, sized, monitored and managed entirely in finite
mathematics, with its pipeline shared as runnable code. On synthetic data the quantum kernel
matches, and does not beat, a classical kernel. The next step is a harder test: a locked signature, a real
consented and governed dataset, and the confirmatory design of Section 4. Part II (Sections 8-10)
applies that design to one named centre, adding the health-economics, funding and clinical-trajectory
analysis a hospital would need before adopting it.

8.1 Why "revenue" means funding in Ontario
Sunnybrook is a publicly funded Ontario hospital, not a seller of oncology services. Its audited
consolidated revenue for the year ended 31 March 2024 was CAD 1,521.8 million, of which CAD 1,054.4
million came from Ontario Health / the Ministry of Health, with hospital-wide drug expense of CAD
186.2 million (ref. 10). High-cost intravenous cancer drugs are largely paid centrally through Ontario
Health's New Drug Funding Program rather than from a hospital's own margin. "Revenue projection"
for the Odette Cancer Centre therefore means projecting funding inflows attributable to the programme -
test funding, trial sponsor income and research grants - against programme costs, and separately
projecting the payer-system costs and savings, because in this funding model the two ledgers do not
move together. That split is the central economic finding of Part II (Section 9).

8.2 Centre anchors (published scale only)
The Odette Cancer Program reports over 12,000 new patients per year and 300,000 patient visits per
year, is Toronto's top provider of radiation treatment, and runs more than 150 active cancer clinical
trials with nearly 10,000 patients participating in research (refs. 9, 11). In October 2026 Sunnybrook
announced the Marg Gillespie Precision Oncology Centre - CAD 29 million in philanthropic support,
7,800 square feet inside the Odette Cancer Centre, expected to open in 2029 and explicitly intended to
expand clinical-trial capacity (ref. 11). That opening year is used below as the model's main adoption
step. Ontario-wide, new cancer cases were projected to rise 25.4% between 2020 and 2030, driven by
population growth and ageing (ref. 12), which supplies the model's volume growth rate.

8.3 The finite economics model
The model is discrete and finite throughout, matching Part I: 10 annual cycles, t = 1..10 for calendar
years 2027-2036, a finite set of cost and outcome parameters, and closed-form sums - no simulation and
no asymptotic claim. Volume grows at the Ontario-implied rate:

                 g = 1.2541/10 - 1 = 0.0229 per year,       Nt = 12,000 (1+g)t,     Testedt = Nt . e . at,

where e = 0.35 is the share of new patients facing a systemic-therapy decision the signature could
inform, and at is the adoption ramp (0.10, 0.25, 0.45, 0.65, 0.80, 0.90, 0.90, 0.92, 0.95, 0.95), stepping up
when the Precision Oncology Centre opens in 2029. Incremental system cost in year t is:

                         D Ct = Testedt . [ ctest + cstaff + p+ c+ - (1-p+) q (cavoid + cAE) ] + F,

with signature-positive prevalence p+, management-change rate q among signature-negative patients,
and fixed programme cost F. Health gain per tested patient, D Q, is not asserted directly: it is derived
from the partitioned-survival trajectories of Section 10 as a discounted monthly sum over the finite
states progression-free (PF), progressed disease (PD) and death, with utilities uPF = 0.80 and uPD = 0.60.
Cost-effectiveness and net present value use the standard finite sums at the Canadian reference
discount rate r = 1.5% for both costs and QALYs (ref. 13):

   ICER = [ sumt D Ct / (1+r)t ] / [ sumt D QALYt / (1+r)t ],          judged against the CAD 50,000 per QALY
                                  reference threshold used in Canadian reviews.

10 Clinical trajectories: what the signature would have to do
Clinical trajectories are modelled as a three-state partitioned-survival system - progression-free,
progressed, dead - with exponential survival (the finite-state analogue of Section 2.4). Standard care is
assigned median progression-free survival (PFS) of 9 months and median overall survival (OS) of 20
months for the tested cohort. The signature-guided hypothesis - deliberately set equal to the Section 4
planning alternative, responder rate 0.30 rising to 0.50 in signature-positive patients - assigns
signature-positive patients (40% of those tested) median PFS of 14 months and OS of 30 months, and
signature-negative patients median PFS of 8 months and OS of 19 months on redirected care. They are
not observed Sunnybrook outcomes, and no Sunnybrook patient trajectory is reported anywhere in this
preprint.

The decision-relevant threshold. Solving the Section 8 cost equation for the management-change rate
q at which the system breaks even gives q = 0.24: the programme pays for itself only if at least about
one in four signature-negative patients actually has management changed by the result. The trial in
Section 4 should therefore pre-register management change as a co-primary implementation endpoint
alongside the interaction contrast. Even the conservative scenario sits below the CAD 50,000 per QALY
reference threshold - but that statement is entirely conditional on trajectory gains that no trial has yet
shown for a QML signature.

Part II limitations. First, exponential trajectories smooth over tumour-specific biology; a real
submission needs tumour-stratified curves. Second, blended drug costs hide wide variation by regimen.
Third, adoption is assumed, not modelled from clinician behaviour. Fourth, Precision Oncology Centre
capital is philanthropy-funded and excluded from operating costs; a full business case must add space,
equipment renewal and workforce. Fifth, equity of access to testing is a design requirement here, not
an analysed outcome.

  # Appendix A - Source code (part 1 of 2)
  # qml_trial.py - QML pharmacogenomic signature + trial simulation
  # Requires: numpy, scikit-learn. Run: python qml_trial.py
  import numpy as np
  from sklearn.svm import SVC
  from sklearn.linear_model import LogisticRegression
  from sklearn.metrics import roc_auc_score, balanced_accuracy_score

  rng = np.random.default_rng(42)

  def make_synthetic(n=600, d=8, noise=0.10):
    X = rng.uniform(0, np.pi, size=(n, d))
    signal = np.sin(X[:,0]) * np.cos(X[:,1]) + 0.5*np.sin(X[:,2]*X[:,3])
    y = (signal > np.median(signal)).astype(int)
    flip = rng.random(n) < noise
    y = np.where(flip, 1 - y, y)
    return X, y

  def quantum_kernel(A, B):
    # k_Q(a,b) = prod_j cos^2((a_j - b_j)/2) [exact, Sec. 2.2]
    diff = A[:, None, :] - B[None, :, :]
    return np.prod(np.cos(diff / 2.0) ** 2, axis=2)

  def run_experiment():
    X, y = make_synthetic()
    Xtr, ytr, Xte, yte = X[:400], y[:400], X[400:], y[400:]
    Ktr = quantum_kernel(Xtr, Xtr); Kte = quantum_kernel(Xte, Xtr)
    q = SVC(kernel="precomputed", C=1.0).fit(Ktr, ytr)
    q_auc = roc_auc_score(yte, q.decision_function(Kte))
    q_acc = balanced_accuracy_score(yte, q.predict(Kte))
    rbf = SVC(kernel="rbf", C=1.0, gamma="scale").fit(Xtr, ytr)
    r_auc = roc_auc_score(yte, rbf.decision_function(Xte))
    r_acc = balanced_accuracy_score(yte, rbf.predict(Xte))
    lr = LogisticRegression(max_iter=1000).fit(Xtr, ytr)
    l_auc = roc_auc_score(yte, lr.predict_proba(Xte)[:, 1])
    l_acc = balanced_accuracy_score(yte, lr.predict(Xte))
    print(f"Quantum kernel AUC={q_auc:.2f} BalAcc={q_acc:.2f}")
    print(f"RBF SVM          AUC={r_auc:.2f} BalAcc={r_acc:.2f}")
    print(f"Logistic reg. AUC={l_auc:.2f} BalAcc={l_acc:.2f}")

  def sample_size_prop1(n_hyp=1000, eps=0.05, delta=0.05):
    # Proposition 1: N >= (ln|H| + ln(2/delta)) / (2 eps^2)
    return int(np.ceil((np.log(n_hyp) + np.log(2/delta)) / (2*eps**2)))

  def n_per_arm(p0=0.30, p1=0.50, alpha=0.05, power=0.90):
    from scipy.stats import norm # or use z = 1.96, 1.28
    z = norm.ppf(1-alpha/2) + norm.ppf(power)
    return int(np.ceil(z**2 * (p1*(1-p1)+p0*(1-p0)) / (p1-p0)**2))

  def expected_time_to_absorption(P, transient_idx):
    # M = (I - Q)^-1 ; expected steps = M @ 1 [Sec. 2.4]
    Q = P[np.ix_(transient_idx, transient_idx)]
    M = np.linalg.inv(np.eye(len(Q)) - Q)
    return M @ np.ones(len(Q))

  def simulate_trial(n_arm=135, p_ctrl=0.30, p_trt=0.50,
               n_sims=10000, seed=1):
    # Two interim looks, Beta(1,1) posterior, Sec. 4.3 rules.
    r = np.random.default_rng(seed)
    wins = 0
    for _ in range(n_sims):
       rc = r.binomial(n_arm, p_ctrl); rt = r.binomial(n_arm, p_trt)
       # Posterior P(p_trt > p_ctrl) by Monte Carlo from Betas
       a = r.beta(1+rt, 1+n_arm-rt, 2000)
       b = r.beta(1+rc, 1+n_arm-rc, 2000)
       if np.mean(a > b) > 0.975: # final efficacy threshold
           wins += 1
    return wins / n_sims # power if p_trt>p_ctrl, else type I error

  # Appendix B - Part II: Sunnybrook Odette 10-year scenario model
  # Anchors: N0=12,000 new pts/yr, 300,000 visits/yr (refs. 9, 11);
  # Ontario incidence +25.4% 2020-2030 (ref. 12); r=1.5% (ref. 13).
  import numpy as np
  N0, VIS0 = 12000, 300000
  g = 1.254 ** 0.1 - 1            # 0.0229 per year
  R = 0.015
  ADOPT = [0.10,0.25,0.45,0.65,0.80,0.90,0.90,0.92,0.95,0.95]
  ELIG, PI_POS = 0.35, 0.40
  TEST, STAFF, FUND = 850, 310, 950         # CAD per tested patient
  FIXED = 2_400_000                   # CAD per year
  TRIAL_REV, TRIAL_COST, ENROL = 18000, 13500, 0.12

  def surv(median_m, t_m): return 0.5 ** (t_m / median_m)

  def dqaly(pfs_w, os_w, u_pf=0.80, u_pd=0.60):
    # Partitioned-survival QALY gain vs standard (med. PFS 9, OS 20 mo)
    def q(pw, ow):
       tot = 0.0
       for m in range(60):
          d = 1 / ((1 + R) ** (m / 12))
          pfs = sum(w * surv(md, m) for w, md in pw)
          os_ = sum(w * surv(md, m) for w, md in ow)
          tot += (u_pf * pfs + u_pd * max(os_ - pfs, 0)) * d / 12
       return tot
    return q(pfs_w, os_w) - q([(1, 9)], [(1, 20)])

  DQ_BASE = dqaly([(0.4,14),(0.6,8)], [(0.4,30),(0.6,19)]) # 0.138

  def annual(change=0.50, avoided=22000, dq=DQ_BASE):
    for t in range(10):
       new = round(N0 * (1 + g) ** (t + 1))
       tested = round(new * ELIG * ADOPT[t]); enrol = round(tested * ENROL)
       funding = tested * FUND + enrol * TRIAL_REV + 600_000 * 1.03 ** t
       hcost = tested * (TEST + STAFF) + enrol * TRIAL_COST + FIXED
       per = (TEST + STAFF + PI_POS * 6000) \
            - (1 - PI_POS) * change * (avoided + 2800)
       sys_cost = per * tested + FIXED
       print(2027 + t, new, tested, round(funding/1e6, 2),
            round(hcost/1e6, 2), round(sys_cost/1e6, 2),
            round(dq * tested))
    # Breakeven: q* = (TEST+STAFF+PI_POS*6000) / (0.6*(22000+2800))
    print("Breakeven change rate q* =",
         round((TEST + STAFF + PI_POS * 6000) / (0.6 * 24800), 2))

  if __name__ == "__main__":
      annual()
